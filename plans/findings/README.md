# Findings

Problems or ideas discovered while working on something else. They are **written down here,
not fixed in passing**: fixing them belongs to its own plan (or a small, explicit fix).

One file per finding: `<module>-<short-slug>.md` with

- **Found while**: the plan or task.
- **What**: the problem, with `file:line` references.
- **Why it matters**: the failure scenario or cost.
- **Suggested next step**: plan, quick fix, or "accept and close".

Delete the file when the finding is resolved (the plan that resolves it links to it).
